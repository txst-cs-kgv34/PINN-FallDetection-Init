# Fall-detector data preparation findings

## Summary

The supplied ADL skeleton archive, demographics, activity table, audited real A11 falls, and approved synthetic A11 falls were converted into 841 architecture-neutral 30 Hz CoM trajectories.

| Class source | Detector label | Prepared trials |
|---|---:|---:|
| Real ADL | 0 | 545 |
| Real A11 Frontfall | 1 | 70 |
| Approved synthetic Physics A11 Frontfall | 1 | 226 |

The resulting binary dataset contains 545 ADL and 296 fall trajectories. These are trial counts, not independent-subject counts, and they should not be randomly split at the trial level.

## Missing-row handling

The source quality rule allows interpolation only when a continuous blank interval is at most three frames, or 0.10 seconds at 30 Hz.

- `S57A03T02`: four isolated single-frame rows repaired.
- `S63A02T04`: one isolated single-frame row repaired.
- `S49A03T01`: excluded because its longest blank run was nine frames.
- `S56A03T03`: excluded because its blank run was four frames.
- `S57A02T03`: excluded because its blank run was six frames.
- `S48A02T05`: excluded because the file was empty.

This avoids manufacturing long motion segments through interpolation. The exact repaired frame indices and exclusion reasons are saved in the output tables.

That extension should be treated as a separate experiment or accompanied by a controlled A11-only result.

## Synthetic-fall scope

All 226 entries from the final approved synthetic manifest were included and resampled from 100 Hz to 30 Hz. Rejected synthetic candidates were not copied into this detector dataset.

The approved files are conditional variants derived from 46 unique real source trials. They are not 226 independent recorded falls. The `split_group` remains the source subject, and `source_real_trial` is retained for traceability.

## CoM trajectory ranges

The fixed initial-foot reference intentionally preserves whole-body translation. This is particularly visible in A08 walking, where `x_m` can reach several meters and the apparent pole angle can become large even without a fall.

| Source | Median maximum absolute theta | 95th-percentile maximum absolute theta | Median maximum absolute x | 95th-percentile maximum absolute x |
|---|---:|---:|---:|---:|
| Real ADL | 6.79° | 69.75° | 0.102 m | 2.409 m |
| Real A11 fall | 70.00° | 88.15° | 1.025 m | 1.518 m |
| Synthetic A11 fall | 50.04° | 88.76° | 0.739 m | 1.380 m |

The large A08 displacement is valid walking translation, not an automatic data error. It is an important hard negative for the detector. The later model should learn temporal behavior rather than classify a single large `x` or `theta` value as a fall.

## Real/synthetic context consistency

For the first 0.40 seconds, every approved synthetic trajectory was compared with the newly prepared 30 Hz version of its real source trial:

- median theta context RMSE: 0.279°;
- maximum theta context RMSE: 1.210°;
- median CoM x context RMSE: 0.564 cm;
- maximum CoM x context RMSE: 1.881 cm.

The small nonzero differences come from preprocessing order: the detector package converts the skeleton directly at 30 Hz, while the generator context previously passed through the audit adapter's 30-to-250-to-100 Hz path before being resampled back to 30 Hz. The agreement is close enough to confirm that the same underlying CoM definition and source trials are being used, while the provenance records preserve this distinction.

## Study conditions

The manifests encode the three planned comparisons without assigning model splits:

1. Real falls + real ADL: 615 trials.
2. Synthetic Physics falls + real ADL: 771 trials.
3. Real and synthetic falls + real ADL: 841 trials.

These totals should not be interpreted as balanced training sizes. After subject-disjoint folds are chosen, the training pipeline may use class weights, balanced batches, or controlled subsampling. Validation and test sets should retain their natural composition and should contain real data only when measuring real-world generalization.

## Required leakage rule

Split subjects before creating windows or performing any resampling for class balance. Every synthetic trajectory must remain in the same training partition as its source subject and source trial. S31 must remain S31 and must not inherit S59's identity.

## Recommended next step

Wait for the architecture decision, then add a detector-training directory that consumes this manifest. That stage should define:

- subject-disjoint folds;
- observation-window length and stride;
- whether the model consumes `theta`, `x`, or their derivatives;
- training-only normalization;
- class weighting or balanced batching;
- sensitivity, specificity, precision, F1, AUROC, AUPRC, and false-alarm rate;
- real-only validation and testing for all three training conditions.

Additional synthetic generation is not recommended before the first downstream detector experiment.
