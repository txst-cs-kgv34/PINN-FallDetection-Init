# S63 A11 front-fall inspection

This viewer contains all five S63 front-fall trials: 776 frames in total. No A11 trial has been automatically excluded.

Open `INSPECT.html` and review the raw skeleton first. For each trial, mark:

1. initial standing;
2. fall onset;
3. one representative descent frame;
4. apparent contact; and
5. post-fall movement.

Use the note field to record any incomplete phase, discontinuity, unusual pose, tracking jump, or absence of post-fall movement. Export the JSON before closing the page.

Provisional review order: T04, T03, T02, T05, T01. This order is based on coverage, repeated rows, review flags, and limb-scale stability; it is not a final inclusion decision.

The shaded frames and `Next review flag` button show raw audit flags. A flag is only a prompt for inspection. It does not mean the frame must be removed.

The filtered view uses a 1.5 Hz Butterworth filter with order 6 per pass. It is a visual comparison only. Phase labels should be based primarily on the raw sequence.
