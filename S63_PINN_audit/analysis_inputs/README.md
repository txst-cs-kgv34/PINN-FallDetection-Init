# Analysis inputs

`S63_A11_phase_notes.json` is the canonical, byte-preserved copy of the phase file exported from the focused A11 inspection viewer.

It contains 25 manual provisional skeleton observations: `initial_standing`, `fall_onset`, `descent`, `apparent_contact`, and `post_fall` for each of `S63A11T01` through `S63A11T05`. The observations were made in raw view at the audit's nominal 30 FPS.

Downstream experiments should copy this file rather than editing it in place. Trial inclusion policy belongs in the downstream experiment configuration, not in this manual observation file.
